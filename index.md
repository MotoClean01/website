<h1>Welcome to MotoClean</h1>

<p>This is a starter Jekyll site for MotoClean. I've created a minimal scaffold so you can host your site on GitHub Pages and use your custom domain <strong>www.motoclean.org</strong>.</p>

<p>What you'll find in this repo:</p>

<ul>
  <li>A simple site layout (in <code>_layouts/default.html</code>).</li>
  <li>A home page (this file).</li>
  <li>A contact page wired to Formspree (replace the form endpoint in <code>contact.md</code>).</li>
  <li>A <code>CNAME</code> file configured for <code>www.motoclean.org</code>.</li>
</ul>

<p>To edit content, change the Markdown files in the repository and push — GitHub Pages will rebuild the site automatically.</p>
